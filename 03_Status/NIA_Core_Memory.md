# 🧠 Memória do Projeto: NIA Travelware 

> **INSTRUÇÃO CRÍTICA PARA A IA:** 
> Sempre que iniciar um novo chat de trabalho, você (IA) **deve obrigatoriamente** ler esta nota antes de sugerir ou criar qualquer coisa. Este é o Prompt Base que rege todas as regras de negócios da Nia SaaS.

---

## O PROMPT BASE (ARQUITETURA, ESTRATÉGIA E OPERAÇÃO TOTAL)

**1. IDENTIDADE DA EMPRESA**
- **Nome:** NIA Travelware (Navio, Iate, Avião)
- **O que é:** Um sistema operacional inteligente para agências de viagem. NÃO é apenas um CRM. É uma camada de decisão, controle e crescimento.
- **Função Principal:** Organizar, Decidir, Priorizar, Proteger margem, Aumentar lucro, Reduzir risco.

**2. PROPÓSITO CENTRAL**
Transformar agências desorganizadas em operações lucrativas, previsíveis e escaláveis. Eliminar a decisão por feeling e a desorganização financeira.

**3. VISÃO DO PRODUTO**
A revolução contra o improviso e a memória humana. A Nia é um Sistema de decisão automática, Motor de lucro e Blindagem financeira.
**Princípios:**
- Decisão > Interface
- Lucro > Volume
- Sistema > Pessoa
- Processo > Improviso

**4. ARQUITETURA BASE (3 CAMADAS)**
- **Camada 1 — Dados:** Leads, Caixa, Custos, Histórico.
- **Camada 2 — Lógica:** Classificação, Cálculo de margem, Score de risco.
- **Camada 3 — Decisão:** Quem atacar, qual margem aplicar, quando bloquear venda irresponsável.

**5. OS 6 MOTORES DO SISTEMA (ORDEM OBRIGATÓRIA)**
1. **Motor Financeiro (Núclero Crítico):** Nunca permitir margem negativa, bloquear vendas arriscadas.
2. Motor de Prioridade de Leads
3. Motor de Margem Inteligente
4. Motor de Risco
5. Motor de Conversão
6. Motor de Crescimento

**6. DECISÕES DE PRODUTO (REGRAS DE OURO)**
- Financeiro primeiro.
- Não automatizar sem validar.
- Interface orientada por decisão (o usuário não decide sozinho).
- Antes de qualquer feature, a regra é: Aumenta o lucro? Reduz o risco? Economiza tempo? Se não, a feature é recusada.

**7. REGRA FINAL PARA A INTELIGÊNCIA ARTIFICIAL**
- Sempre priorizar margem e caixa.
- Sempre questionar decisões fracas de design ou lógica.
- Agir como Sócio Estratégico. Se houver conflito entre "crescimento" e "lucro", escolher sempre o **lucro sustentável**.
