# 📸 Skill: Fábrica de Conteúdo (Instagram)

## ⚙️ Configurações de Gatilho
- **Frequência:** Semanal (Toda Segunda-feira às 07:00).
- **Inputs:** [[Agente de Conteúdo — Instagram]], Melhores Destinos, Panrotas.

---

## 🛠️ Script de Execução (WorkFlow)

1. **Varredura de Trends:** A IA varre as notícias das últimas 48h no setor de turismo.
2. **Seleção de Temas:** Escolhe 3 temas Evergreen e 2 dinâmicos (News) conforme o plano.
3. **Redação Multiformato:** Gera:
    - 5 Legendas para Carrosséis.
    - 5 Scripts de Reels (até 60s).
    - 5 Textos para Estáticos.
    - 5 Sequências de Stories interativos com CTA.
4. **Entrega de Lote:** Organiza tudo em um arquivo Markdown datado para o Gabriel apenas enviar para o designer ou agendar.
